# Simple Guide - One-Tap Translation

## ✨ Now Super Easy! Just ONE Button!

Your app now works with **just ONE tap** - no more copying, pasting, or multiple steps!

## How It Works Now

### Step 1: Setup (Do Once)

1. Open Bhasha app
2. Go to Settings (gear icon)
3. Turn ON "Overlay bubble active"
4. **Important**: Tap "Enable accessibility" button
5. In the settings that open, find "Bhasha" and turn it ON

### Step 2: Using It (Every Time)

1. Open WhatsApp, Messages, or any app
2. Tap in the text box and type your message in Kannada
3. **Tap the blue "T" button** (floating on your screen)
4. **Done!** Your Kannada text automatically becomes English!

## What the Button Does Automatically

When you tap the blue "T" button:

- ✅ Reads your typed text
- ✅ Translates Kannada → English
- ✅ Replaces the text automatically
- ✅ Shows "✓ Translated!" message

## Important Notes

### The Blue "T" Button

- It floats on your screen
- You can drag it anywhere
- Works in ALL apps (WhatsApp, Messages, Email, etc.)

### Accessibility Permission

- **Must enable this** for one-tap to work
- It's safe - only Bhasha uses it
- Lets the app read and write text for you

### If It Doesn't Work

- Make sure you tapped in a text box first
- Check if accessibility is enabled
- Restart the app if needed

## For Children/Family: How to Help Setup

1. Install Bhasha app
2. Enter Sarvam API key (in settings)
3. Select: Kannada → English
4. Turn ON "Overlay bubble"
5. **Enable accessibility service** (most important!)
6. Show them how to tap the blue button once

## Practice Together

1. Open WhatsApp
2. Tap to write a new message
3. Type: "ನಾನು ಚೆನ್ನಾಗಿದ್ದೇನೆ"
4. Tap the blue "T" button
5. Watch it change to: "I am fine"

Do this 2-3 times so they remember!
