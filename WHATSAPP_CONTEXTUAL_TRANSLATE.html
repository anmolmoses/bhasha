Provider boundary

Vision here.
Language there.

Sarvam stays the language engine. OpenAI receives no instruction to translate and returns only source text plus normalized geometry.

01 / OCR ONLY

OpenAI

Receives one base64 JPEG through /v1/responses with store:false and detail:original. Returns at most 40 blocks on a 0–1000 canvas.

→
02 / TRANSLATION ONLY

Sarvam

Receives each extracted source string through Mayura v1. Bhasha preserves its rectangle and maps the translated string back to the same location, with four bounded requests in flight.

OpenAI never translates · Sarvam never receives the screenshot

Runtime

One consent.
One frame.

The capture token is requested for every action, used once, and stopped as soon as a frame is available.

Double tap

The pending single tap is cancelled. Bhasha checks that screen translation was explicitly enabled.

Android consent

A transparent permission activity opens the system MediaProjection prompt. Bhasha cannot silently approve it.

Capture & read

The bubble hides, ImageReader collects one frame, compresses it in memory, then immediately stops projection.

Translate & cover

OpenAI locates text, Sarvam translates each block, and a modal overlay draws white labels. Tap anywhere to close.

Privacy contract

Visible consent,
short memory.

Screen OCR is more sensitive than accessibility-node translation, so it has its own key, setting, disclosure, Android consent, and foreground-service notification.

What Bhasha guarantees

  • The screenshot is kept in memory and never written to a Bhasha file.
  • OpenAI is asked only for exact text and bounding rectangles.
  • The OpenAI request sets store:false.
  • Sarvam receives extracted strings, never the screenshot.
  • Both API keys are stored with Flutter Secure Storage.
  • Android secure windows may return a blank frame and remain untranslated.
  • No capture begins without the system MediaProjection dialog.

Your test sequence

Open any app.
Double-tap Bhasha.

  1. Open Bhasha Settings.
  2. Save the Sarvam API key.
  3. Save the separate OpenAI screen OCR key.
  4. Enable “Double-tap screen translation” and accept the disclosure.
  5. Turn on the floating bubble.
  6. Open WhatsApp or another app with visible text.
  7. Double-tap the T, approve Android capture, then wait for white translated labels.
  8. Tap anywhere to close. Single tap and drag should still behave normally.
